# Way Mod — Fabric 1.21.11

Мини-мод для Minecraft **1.21.11** (Fabric Loader 0.20.1, Fabric API 0.141.6+1.21.11).
Версия мода: **1.1.1**. Языки: русский (`ru_ru`) и английский (`en_us`).

> **v1.1.1:** **Все спавнеры крафтятся** — Вей-спавнер (решётки + око Эндера), Спавнер (HHN) (алмазы + решётки + око) и даже ванильный спавнер (решётки + око). **Ядра удалены из мода совсем** — вся прокачка ванильными предметами: сахар / редстоун / изумруд / железо / сундук. Команды как прежде: выдача — оператор или креатив.

## Что в моде

### v1.0.0 — основа
1. **Блок перехода** (`way_block`): ПКМ по блоку — телепорт в заданное измерение/координаты. Shift+ПКМ — вернуться в точку, откуда был сделан последний телепорт.
2. **Вей-спавнер** (`craftable_spawner`): спавнер, который с **1.1.1** снова **крафтится** из железных решёток и око Эндера (в выживании тоже); моб задаётся командой или яйцом спавна; сахар (ПКМ) ускоряет без предела; старое имя «Крафтовый спавнер» — теперь только про id блока.
3. **Команда `/way`** — выдаёт настроенные предметы и мгновенно переправляет игрока.

### v1.1.0 / v1.1.1 — Spawner  и логистика
4. **Спавнер (HHN)** (`spawner_2000_pro`) — автоматический спавнер от Hothawk Network {см. ниже}»:
   - **крафтится** (алмазы + решётки + око Эндера — рецепт ниже), командная выдача тоже есть;
   - спавнит мобов **строками**: по умолчанию 3 строки (по мобу в каждую), железом расширяется до 12; лимит живых существ: по умолчанию 10, максимум **150**;
   - обычный интервал — 5 секунд; **сахаром ускоряется без предела** (хоть до 1 тика);
   - **режим «фарм»** (вкл. редстоуном, выкл. изумрудом): заспавненные мобы автоматически умирают, а их добыча **размножается ×5** («Добыча 5» на пальцах);
   - моб задаётся `/way spawnerpro <моб>`, яйцом спавна (ПКМ по блоку) или `/way spawnerpro` + яйцо.
5. **Ванильная прокачка** (ПКМ по любому спавнеру — модному или ванильному; работают у всех, предметы расходуются):
   - **сахар** — ускорение: −2 тика задержки за штуку, **без предела** (хоть до 1 тика) — работает на **всех** спавнерах: ванильном, Вей-спавнере и Спавнере (HHN);
   - **редстоун** — включает «фарм» (авто-убийство, добыча ×5);
   - **изумруд** — выключает «фарм» обратно;
   - **железный слиток** — +1 строка: спавнит на одного моба за раз больше (до 12);
   - **сундук** — +10 к лимиту живых мобов (до 150).
6. **Авто-воронка** (`auto_hopper`) — собирает предметы **со всего чанка** (все предметы-сущности в границах чанка по всей высоте мира) и складывает их в **соседний контейнер** (сундук, бочка, другая авто-воронка — любые):
   - ПКМ **с предметом в руке** — добавить предмет в фильтр;
   - Shift+ПКМ с предметом — убрать из фильтра;
   - ПКМ **без предмета** — показать фильтр;
   - Shift+ПКМ без предмета — очистить фильтр;
   - **пустой фильтр = собирает всё**; заполненный — только перечисленное.
   Работает в связке с передатчиком (см. ниже) — можно строить сортировочные фабрики в чанке.
7. **Воронка-передатчик** (`hopper_transmitter`) — перекидывает ресурсы из сундука/воронки **в другой контейнер** (свой, соседний, на другой стороне склада):
   - **Shift+ПКМ** по передатчику (с пустой рукой или с любым предметом — не важно) — «прицелиться»;
   - затем команда **`/way link <координаты>`** (координаты поддерживают `~`) привязывает цель: ближайший на прицеле контейнер по координатам;
   - дальше каждые 10 тиков передатчик тянет предметы из контейнера **за ним** (или любого соседнего) и вставляет в **привязанный** контейнер;
   - передатчики работают и с авто-воронками: авто-воронка складывает в сундук, передатчик тянет из сундука и отправляет на склад.
8. **`/way spawnerpro <моб>`** — выдаёт Спавнер (HHN) сразу с заданным мобом.

## Команды

| Команда | Что делает |
|---|---|
| `/way give <измерение> <x> <y> <z>` | Выдаёт блок перехода с записанной целью телепортации |
| `/way set <измерение> <pos>` | Задаёт цель существующему блоку перехода на позиции (координаты поддерживают `~`) |
| `/way spawner <моб>` | Выдаёт Вей-спавнер с выбранным мобом |
| `/way spawnerpro <моб>` | Выдаёт Спавнер (HHN) с выбранным мобом |
| `/way link <pos>` | Привязывает передатчик (после Shift+ПКМ по нему) к контейнеру на позиции |

Примеры:

```
/way give overworld -1412 69 121
/way give nether -1412 69 121
/way give the_end -1412 69 121
/way give minecraft:overworld -1412 69 121   ← то же самое, полный id
/way set nether ~ ~-2   ← задать цель блоку перехода на 2 блока южнее-севернее (по взгляду ~)
/way spawner zombie     ← можно и minecraft:zombie
/way spawnerpro minecraft:wither_skeleton
/way link ~ ~3 ~        ← привязать передатчик к сундуку на 3 блока выше
```

Псевдонимы измерений: `overworld`, `nether`, `the_end`; можно указывать и полный id (`minecraft:overworld`, `minecraft:the_nether`, `minecraft:the_end`).

Права (с 1.1.0):

| Ветки | Кому доступно |
|---|---|
| `/way give`, `/way set`, `/way link` | оператор (как `/gamemode`) |
| `/way spawner`, `/way spawnerpro` | оператор **или** игрок в креативе |
| выживание без прав | может **крафтить все спавнеры** (Вей-спавнер, Спавнер (HHN), ванильный), но ветки `/way spawner`/`/way spawnerpro` не видны |

## Как работает телепорт

- ПКМ на **блоке перехода** (не сидя):
  - если у блока есть цель — телепорт в место цели: вы появитесь на полу блока с координатами `x+0.5, y, z+0.5`, поворот камеры сохраняется;
  - точка, где вы стояли перед телепортом, запоминается (при смерти сохраняется тоже);
  - **Shift+ПКМ** по любому блоку перехода — вернуться в запомненную точку.
- Если у блока ещё нет цели — подсказка сообщит об этом.

## Как жить со Спавнером HHN

1. Скрафтите блок (`spawner_2000_pro`: алмазы + решётки + око Эндера) или получите готовый: `/way spawnerpro zombie` (оператор/креатив).
2. Моб ставится:
   - командой при выдаче (`/way spawnerpro zombie`), **или**
   - ПКМ по блоку **яйцом спавна** (например, яйцо зомби), **или**
   - `/way spawnerpro` + яйцо — комбинировать не обязательно, но можно.
3. Прокачка ванильными предметами — просто **ПКМ по блоку с предметом в руке**:
   - сахар: −2 тика за штуку (5 с → … → 0.5 с → хоть каждый тик);
   - редстоун: включает режим «фарм», изумруд — выключает;
   - железо: +1 строка (3 → до 12); сундук: +10 лимита (10 → до 150).
4. **Редстоун + авто-воронка = ферма без рук**: мобы спавнятся, умирают, добыча ×5, воронка собирает её **со всего чанка** в сундук, передатчик дотягивает до склада.
5. Спавн продолжается, даже если игрок отошёл (тик блок-сущности работает в загруженных чанках; лимит живых считается в области ±8 блоков по X/Z).

## Крафты

Блок перехода (обсидиан + жемчуг Края + око Эндера):

```
[O P O]      O = обсидиан (minecraft:obsidian)
[O E O]      P = жемчуг Края (minecraft:ender_pearl)
             E = око Эндера (minecraft:ender_eye)
```

Спавнер (HHN) (алмазы + решётки + око Эндера):

```
[D B D]      D = алмаз (minecraft:diamond)
[B E B]      B = железная решётка (minecraft:iron_bars)
[D B D]      E = око Эндера (minecraft:ender_eye)
```

Ванильный спавнер тоже крафтится (решётки + око Эндера):

```
[B B B]      B = железная решётка (minecraft:iron_bars)
[B E B]      E = око Эндера (minecraft:ender_eye)
```

Вей-спавнер (железные решётки + око Эндера) — **в выживании тоже**:

```
[# E #]      # = железная решётка (minecraft:iron_bars)
[# # #]      E = око Эндера (minecraft:ender_eye)
```

Авто-воронка (железный слиток + воронка):

```
[I H I]      I = железный слиток
             H = воронка (minecraft:hopper)
```

Воронка-передатчик (жемчуг Края + воронка + редстоун):

```
[P H P]      P = жемчуг Края
[R H R]      H = воронка
             R = редстоун (minecraft:redstone)
```

Точные JSON лежат в `src/main/resources/data/waymod/recipe/` (и рецепт ванильного спавнера — в `src/main/resources/data/minecraft/recipe/`) — правятся датапаком без пересборки.

## Установка готового мода

1. Убедитесь, что стоит загрузчик Fabric и Fabric API **0.141.6+1.21.11** (версия API указана в `gradle.properties`).
2. Скачайте/соберите мод (см. ниже) — файл `build/libs/waymod-1.1.1.jar`.
3. Положите jar в папку `mods` и запустите игру.

## Сборка из исходников

Нужно: **Java 21** (например, Adoptium Temurin 21) и интернет (первая сборка скачает Minecraft ~1 ГБ, потом используется кеш).

Windows:
```bat
gradlew.bat build
```
Linux/macOS:
```sh
./gradlew build
```

Готовый jar появится в `build/libs/`. Заодно собирается `-sources.jar` — это нормально.
Если что-то пойдёт не так: `gradlew.bat clean build`, либо `gradlew.bat --stop` (убить демоны Gradle и попробовать снова).

Текстуры можно перегенерировать (уже сгенерированы):
```bat
powershell -ExecutionPolicy Bypass -File tools\make_textures.ps1
```
